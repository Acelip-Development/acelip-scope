## Host observations

- Distro: Ubuntu 26.04.1 LTS, ID `ubuntu`, version ID `26.04`, ID_LIKE `debian`,
  family `debian`.
- Desktop/session: GNOME / Wayland; session name `ubuntu`.
- Available portal backend candidate: `gnome`, established through an acquired
  bus name. This does not prove ScreenCast call dispatch or capture success.
- Discord: deb package version `1.0.159`. Snap and Flatpak queries confirmed
  no Discord installation in their inspected scopes. RPM/pacman/zypper tools
  are absent; these ecosystems were tested using fixtures only.
- CPU: discovered k10temp/Tctl, not a generic maximum of all temperatures.
- Cooling: discovered Kraken driver exposes coolant temperature, pump speed
  and fan speed. No hardware IDs or current readings are hard-coded.
- Sharing: PipeWire/WirePlumber services available; ScreenCast advertises zero
  source types. End-to-end validation remains **PARTIAL/unverified**. The optional
  test is still manual and user-reported; no actual capture was initiated.

The old `flatpak info --show-version` probe was rejected by the installed CLI.
It was replaced with supported structured `flatpak list` columns. Query failures
are no longer confused with confirmed package absence.

## Scope and limitations

Linux is implemented. Only this Ubuntu/GNOME session was live-validated.
Debian, Fedora/RHEL, Arch, openSUSE and other desktop detection branches are
fixture-tested, not certified on installed systems. Windows/macOS placeholders
execute no diagnostics and return UNSUPPORTED. Their native GUI packaging is
not implemented. Non-systemd service managers and non-Debian package integrity
audits are explicitly unsupported. NVIDIA telemetry remains the implemented GPU
query path; non-NVIDIA live GPU metrics are not claimed.

Manual/AppImage discovery is limited to available executable paths, and native
Chromium sandbox enforcement is not validated. Portal bus ownership establishes
availability only. Privacy filtering remains best effort with explicit preview.

No system packages, services, desktop settings, drivers or installed user
integration files were changed. All project changes remain local; no push or tag.
Only local preferences, operational logs/caches and explicitly requested QA
artifacts persist. There is no diagnostic history or automatic AI handoff.
