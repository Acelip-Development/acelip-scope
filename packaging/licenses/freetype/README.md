# FreeType license supplement

`FTL.TXT` is unmodified upstream FreeType 2.14.3 material, retrieved from
[the exact manifest source commit](https://github.com/freetype/freetype/blob/0a0221a1347e2f1e07c395263540026e9a0aa7c7/docs/FTL.TXT).
SHA-256: `5a5ee54c5001bbad1cdc1a57cc3dd4c42199b2da09d39c7ee41fab002d02967f`.

The pinned GNOME runtime supplies only the FreeType license overview. The
AppImage builder adds this file at the overview's referenced `docs/FTL.TXT`
location. The project NOTICE supplies the binary-distribution acknowledgement.
The FTL route is selected; GPLv2 is an alternative, not an additional obligation.
The upstream contact addresses in this exact text are public license material.

This supplement resolves the missing main license text, not every component's
redistribution gate. See [licensing notes](../../../docs/LICENSING-NOTES.md) for
contributed-code notice review, the downstream patch, and remaining obligations.
